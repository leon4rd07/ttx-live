Drop the official Maybank logo files here.

  logo.svg        shown on the light theme   (also the fallback on dark)
  logo-dark.svg   optional knockout/reversed version for the dark theme

SVG is preferred; .png works if you rename the reference in src/App.jsx
(LOGO_LIGHT / LOGO_DARK, near the top of the file).

Sizing is handled by CSS — the header caps it at 22px tall, the projector at
38px. Supply the asset at its natural aspect ratio and it will fit.

If neither file is present the app renders no logo at all and the text
wordmark stands alone, so nothing breaks by leaving this folder empty.

Use the approved asset from whoever owns the brand at Maybank. Do not
substitute a redrawn or traced copy.
